# `data/` 配置说明

数值与配置都在这里，脚本里不要写死数字。

## 归属

| 谁 | 管什么 |
| --- | --- |
| P2（星辰） | 所有数值：塔、敌人、波次、卡牌、商店、起始牌组 |
| P1（Siri） | 读这些文件的结构，`scripts/data/` 里写加载类；结构要改先发群里 |
| P3（坤坤） | 只读，用于界面显示与打包校验 |

改数值一律走 PR，并在群里说一句改了哪个值、为什么，别直接推 main。

## 格式

当前用 **JSON**，理由：不依赖任何 `.gd` 类，P1 还没写 Resource 类时双方就能并行；Godot 4 用 `JSON.parse_string` 或 `FileAccess` 直接读，不用额外插件。

如果 P2 之后决定改成 `.tres`，必须同时提供：① Resource 类脚本路径 ② 一份与现有 JSON 字段一一对应的迁移表 ③ 通知 P1 改加载代码。**不允许两种格式并存。**

## 单位约定（别自己换算）

- 地图格边长 **30 单位**，普通敌人判定框 **25×25**，取其中心所在 1×1 格的中心点
- 攻击范围与攻击半径用**格数**，速度用**格/秒**
- 攻击间隔、持续时间用**秒**，技能牌的计时按秒算，不用帧
- 击杀任一敌人奖励 **50 费用**，由 P2 结算，P1 只发 `enemy_killed`
