# 启动说明

《守望》Windows 版试玩包的运行方法与已知情况。**给评委、队友和任何拿到 exe 的人看这一份就够。**

---

## 一、怎么开始玩

1. 找到 `build/win64/守望.exe`（单文件，约 111 MB，不用安装）。
2. **双击运行**。不需要装 Godot、不需要装运行库，游戏引擎已经打包在里面了。
3. 看到深灰底、正中「守 望」标题、下面「开始游戏」和「退出」两个按钮，就是启动成功了。
4. 点「开始游戏」进入流程，点「退出」关闭游戏。

> 建议把整个 `build/win64/` 文件夹一起拷走（现在里面只有 exe 一个文件，以后若加了外部素材也会放这里），不要只拷 exe 到别的目录——那样目前能跑，但加素材后会找不到文件。

## 二、系统要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 |
| 显卡 | 支持 OpenGL 3.3 的集成显卡即可（渲染器为 gl_compatibility，不吃独显） |
| 内存 | 2 GB 以上 |
| 分辨率 | 1280×720 起，窗口可缩放，界面按 canvas_items 等比拉伸 |
| 硬盘 | 约 120 MB（首次运行还会在用户目录再生成几 MB 着色器缓存） |
| 网络 | 不需要，全程离线 |

## 三、退出方式

三种都行，任选其一：

1. 主菜单点「退出」按钮。
2. 点窗口右上角的 × 。
3. `Alt + F4`。

游戏是**即时保存型**的：目前没有存档文件，关掉就是关掉，下次从头开始。这一点在做出「关卡进度保存」之前不会变，别指望关掉再开能接着打。

## 四、日志与用户数据在哪

Godot 导出的程序会把运行日志和缓存写到用户目录，**不在 exe 旁边**：

```
C:\Users\<你的用户名>\AppData\Roaming\Godot\app_userdata\守望\
├── logs\          # 每次运行的 godot.log，报错看这里
└── shader_cache\  # 着色器缓存，可随时删，首次启动会重建
```

`AppData` 是隐藏目录，地址栏直接粘贴上面那行就能进。

**提交 bug 时请附上 `logs\godot.log`**，否则只能靠猜。

## 五、常见问题

**Q：双击后 Windows 弹出「已保护你的电脑」/ SmartScreen 蓝色窗口。**
A：正常现象。exe 没有买代码签名证书，Windows 对任何没签名的程序都这么提示。点「更多信息」→「仍要运行」。评委机器上也会遇到，答辩时可以直接说明。

**Q：双击后一闪就没了，或者没有任何窗口。**
A：先看 `logs\godot.log` 最后几行。最常见的是显卡驱动太老、不支持 OpenGL 3.3。可以试：右键 exe →「以管理员身份运行」；或更新显卡驱动。

**Q：界面中文变成方块「□□□」。**
A：说明字体没加载上，属于打包事故，请把 exe 和你的系统版本报给我们。当前版本已内置 Noto Sans SC，正常不会出现。

**Q：点了「开始游戏」没反应，日志里有一行红字说「场景缺失 res://scenes/boot/deck_select.tscn」。**
A：这是**当前版本的已知状态**，不是你的机器坏了。起始牌组选择界面还在开发中（P3 的 T6），流程会故意停住并报错，不会崩溃。等 T6 合入后这个提示就消失。

**Q：没有声音。**
A：当前版本的音频总线还是空实现（`scripts/core/audio.gd` 里 `play_sfx` / `play_bgm` 都是 `pass`），**不是你的声卡问题**，是音效还没接。接上之后这份说明会更新。

**Q：能不能全屏？**
A：可以，窗口右上角最大化即可。界面按 1280×720 基准等比拉伸，最大化后不会错位。

## 六、给队友：怎么自己打一个包

```powershell
# 1) 先关掉正在运行的旧包，否则导出会因为文件被占用而失败
Get-Process -Name 守望,shouwang -ErrorAction SilentlyContinue | Stop-Process -Force

# 2) 导出（用的是 export_presets.cfg 里的 "Windows Desktop" 预设）
& "C:\godot\Godot_v4.7.2-stable_win64_console.exe" --headless `
  --path "C:\Users\<你>\Desktop\shouwang" `
  --export-release "Windows Desktop" `
  "C:\Users\<你>\Desktop\shouwang\build\win64\守望.exe"
```

三个必须知道的坑，踩过一次就够了：

1. **新增字体或图片后，必须先让编辑器导入一次再导出。** 否则报 `No loader found for resource: ...otf (expected type: FontFile)`，exe 会缺字体、中文全变方块。做法：先跑一次 `--headless --path <仓库> --editor --quit`，等 `.import` 生成出来，再导出。
2. **导出前一定要杀干净正在运行的旧包。** 否则报 `PCK 内嵌: 重命名临时文件"....tmp"失败`，并留下一个 111 MB 的 `.tmp` 垃圾文件。
3. **`build/` 已在 `.gitignore` 里，不要提交 exe。** 包发给群里，不进仓库。

打完之后请按本文件第一节自己双击跑一遍——**没在真机上跑过的包不算验收**（这条写在 `docs/仓库搭建与协作规范.md` 里）。
