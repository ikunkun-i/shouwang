## 已知的冲突点（避免踩）

1. **“反应堆区”**：v1.0 里没有此机制，基地定时产费即费用来源，不要按旧稿再做一套。
2. **七设施收缩为 4 种塔**：单体炮台、范围放电、减速场、维修塔。
3. **单一费用 + 关间代币**：战斗内只认费用，商店只认代币，不要混用。
