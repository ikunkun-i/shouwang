## 已知的冲突点（避免踩）

1. **“反应堆区”**：v1.0 里没有此机制，基地定时产费即费用来源，不要按旧稿再做一套。
2. **塔型从 4 种收缩为 3 种**：`plan-v2.0-master.docx` 把塔定为 A 直线输出 / B 阻挡 / C 范围输出，原“减速场”“维修塔”改由冰冻地块技能与修理技能牌承担。以 v2.0 为准。
3. **单一费用 + 关间代币**：战斗内只认费用，商店只认代币，不要混用。

## 版本关系（v1.0 与 v2.0 主策划案）

**已拍板（2026-11-27）：塔型取 3 种，世界观取星际撤离线。以下差异表中右列全面生效，左列仅作对照留存。**
