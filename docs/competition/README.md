## 六个创作方向（原文摘要）

1. 抗倭叙事：围绕守卫家园、沿海抗倭历史开展剧情与冒险创作。
2. 城堡防御：结合永昌堡建筑与防御体系，创作塔防、策略等游戏。
3. 家族传承：围绕宗族文化、人物故事和家风传承。
4. 节庆巡游：结合汤和信俗巡游、传统表演与节庆民俗。
5. 水乡生活：永昌堡水乡建筑、民居生活与耕读文化、“十三进士”家风家训。
6. 未来想象：结合历史文化与 AI、未来科技，探索跨时空互动表达。

## 对我们的用处

- **主方向是第 2 条「城堡防御」**，与我们的塔防玩法完全对应，申报表里直接引这条。
- **侧重方向可报第 6 条「未来想象」**（AI 参与开发）。比赛要求选 2 个侧重点，第 2+6 组合写起来最省力：玩法落在城堡防御，制作过程落在 AI 使用。
- 封面底图是永昌堡城墙与券门的线稿，美术可拿它当构图参考；但**世界观已经拍板走星际撤离线**，建筑与配色可借，剧情不要套抗倭史实，避免和玩法设定打架。
- 若答辩被问“为什么用科幻设定做城堡防御”，答口径：塔防的“守”与永昌堡的“守城”同构，形式换成星际撤离，落点仍是守卫与等待。
